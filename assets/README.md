# 日本語フォント

`NotoSansJP-Regular.ttf` は Noto Sans JP の可変TTFをweight 400に固定した静的TrueTypeフォントです。配布元は [Google Fonts](https://github.com/google/fonts/tree/main/ofl/notosansjp) です。

フォントのライセンスはSIL Open Font License 1.1で、コードのMITライセンスとは別です。著作権表示とライセンス全文を `NotoSansJP-LICENSE.txt` に保持しています。再配布時も両ファイルを同梱してください。

`--font /path/to/font.ttf` で別の日本語TrueTypeフォントを指定できます。別フォントの利用・PDF埋込み・再配布条件は、そのフォントのライセンスをご確認ください。
